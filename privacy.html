Privacy Policy

Campbell Content Studio · Last updated October 17, 2026

This policy covers "Daily Brief," a private tool built and used only by the owner of Campbell Content Studio. It is not offered to the public.

What the app accesses

  • Google Calendar (read-only): reads upcoming events to list them in a daily summary. It cannot create, change or delete events.
  • Gmail (send-only): sends the daily summary email to its owner. It cannot read, search or delete any email.
  • Google Drive (app-created files only): creates and reads only the files the app itself made (the daily summaries, a to-do list and a log). It cannot see any other files.
  • YouTube Data API: reads public channel statistics only.

How data is used

Data is used only to produce the owner's daily summary. Calendar entries and the app's own documents are sent to the Anthropic Claude API to write that summary. Nothing is sold, shared for advertising, or used for any other purpose.

Storage

Summaries are stored in the owner's own Google Drive. Access credentials are stored as encrypted secrets and are never published.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
